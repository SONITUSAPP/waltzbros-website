# Waltz Brothers website

Public site at https://project-trgx7.vercel.app. Every commit to `main` is published automatically by Vercel (about 30 seconds).

- `index.html`: the whole homepage (text, layout, styles)
- `images/`: photos. To swap one, upload a new file with the same name

To change text: open `index.html` on github.com, click the pencil icon, use Ctrl+F to find the words, edit them, then click "Commit changes".

Rules: the public site shows Waltz precision and heritage messaging only. AI tools stay internal. No ITAR-controlled or export-controlled technical data goes in this repo.
